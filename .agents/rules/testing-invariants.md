# NON-NEGOTIABLE RULE: NO UNTESTED CLAIMS

1. **Empirical Verification Requirement**: Never claim a bug is fixed, a component is working, or a pipeline/browser feature is ready without empirical runtime proof (passing unit tests, executed commands, or `pnpm gate` results).
2. **Raw Test Evidence**: Every completion report must cite the exact test command executed and show the actual pass/fail metrics.
3. **Mandatory Unverified Tag**: Any change or claim that has not been executed and empirically verified must be labeled **NOT VERIFIED**.
