# ADR-033 — AI-Native Studio Repositioning

- **Date:** 2026-06-17
- **Status:** Accepted
- **Supersedes:** Generic agency positioning in BRAND.md, PHASE-D-REVENUE-FLYWHEEL Gumroad-first GTM, $500 starter pricing in FOUNDER-PROFILE.md

## Context

Turicks is pre-revenue, solo (~10h/week, ~$0 budget), with a production multi-agent OS (FounderOS: live, ~1,098 tests, HITL + eval + audit). Prior strategy docs positioned Turicks as a generic "SaaS development partner" for SME founders ($50K–500K ARR) with a $500 starter tier and Gumroad-first revenue flywheel (PHASE-D-REVENUE-FLYWHEEL.md).

2026 market research (YC Spring RFS, AI commoditization data, acquisition channel analysis) showed:
- **AI-native agency** thesis is YC-validated: sell finished work, software margins
- Value moved from building to **trust/governance, taste, distribution**
- FounderOS already *is* the trust moat (HITL + eval + audit)
- Solo operator channels: referrals, founder-led LinkedIn, low-volume Proof Drops, awards

## Decision

Lock **The Autonomous Studio** repositioning:

| Fork | Decision |
|------|----------|
| **Positioning** | AI-native studio + design as anti-commoditization *finish* (NOT equal-pillar; NOT design-led) |
| **Niche** | AI / dev-tool startups (funded; need launch experience proving cutting-edge) |
| **Team** | Effectively solo — founder executes + learns design craft |
| **Revenue goal** | 1 client/month @ ≥$8K = $96–240K/yr solo |
| **Pricing floor** | $8K project / $5K-mo retainer; **retire $500 starter** |
| **GTM split** | ~70% positioning/proof/distribution, ~30% build |
| **FounderOS build** | Deferred until SCALE gate ($5K+ banked from client work) |

## Consequences

### Positive
- Sharp ICP enables targeted Proof Drops and build-in-public content
- FounderOS becomes delivery moat narrative, not just internal tool
- Premium pricing filters commodity buyers
- Clear phased roadmap with measurable gates

### Negative / trade-offs
- Gumroad info-product revenue deprioritized (was Phase D plan)
- SaaS pivot (Phase E) further deferred — studio revenue first
- Showcase build requires founder to learn cinematic design craft (time investment)
- Old docs (ROADMAP, BRAND, FOUNDER-PROFILE, PHASE-D-REVENUE-FLYWHEEL) must be updated or archived
