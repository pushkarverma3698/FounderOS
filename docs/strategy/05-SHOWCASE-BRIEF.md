## Showcase Standards

Each piece must demonstrate:
1. **Pillar A** — mention governed delivery (HITL/audit) in case study copy
2. **Pillar B** — cinematic-web preset with visible craft (motion, typography, depth)
3. **FounderOS meta** — document real build metrics (time, tool calls, eval pass) in LinkedIn post

**Bar:** Would you pay $8K for this quality? If not, don't ship.
