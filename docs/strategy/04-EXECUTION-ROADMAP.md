# Execution Roadmap — Phased GTM

> **Realistic at:** solo / 10h-week / $0 budget · **Locked:** 2026-06-17

---

## Phase overview

| Phase | Window | Focus | Gate to advance |
|-------|--------|-------|-----------------|
| **0 — Foundations** | Wk 1–2 | Doc set, positioning, 30-account target list | Docs done + target list |
| **1 — Proof** | Wk 2–6 | 3 showcase pieces → proof.turicks.com → award submissions | 3 showcases live + ≥1 award submission |
| **2 — Distribution** | Wk 3+ (ongoing) | Founder-led build-in-public on LinkedIn | Cadence running 4+ weeks |
| **3 — Outreach** | Wk 6+ | Proof Drops to target list | 3–5 qualified convos/mo |
| **4 — Close + referrals** | After client #1 | Deliver, systematize referrals, case study | 1 client closed |
| **SCALE gate** | Money in | Build FounderOS delivery depts + contractors | $5K+ banked |

## Phase 1 — Proof (Week 2–6)

**Goal:** 3 showcase pieces = $10K-grade AI/dev-tool launch experiences.

- Build 3 self-initiated showcase projects (see [05-SHOWCASE-BRIEF.md](05-SHOWCASE-BRIEF.md))
- Host on `proof.turicks.com`
- Submit ≥1 to Awwwards/Godly/Land-book
- Document build process on LinkedIn (build-in-public)

**FounderOS build:** ~30% — helper tools only if needed (`gen_asset` for design pipeline).

---

## Phase 2 — Distribution (Week 3+, ongoing)

**Goal:** Sustainable inbound pipeline via founder-led content.

Weekly cadence:
- **Mon:** FounderOS metric / lesson post
- **Wed:** Showcase WIP or technical deep-dive
- **Fri:** Governed AI thesis / industry take

Use marketing department for draft → HITL approve → post.

---

## Phase 3 — Outreach (Week 6+)

**Goal:** 3–5 qualified conversations/month.

- 2–3 Proof Drops/week to target list
- Each Drop = custom artifact built via FounderOS
- Track responses in founder_context / CRM (manual OK at solo scale)

**Deferred until Phase 3:** Proof Drop engine (`scout` workflow) — build when volume justifies it.

---

## Phase 4 — Close + Referrals (After client #1)

- Deliver with full FounderOS audit trail
- Case study (with permission)
- Referral ask + 10% bonus program
- Systematize delivery checklist

---

## SCALE gate — FounderOS feature build

**Only after $5K+ banked from client work:**

| Feature | Purpose | Reuses |
|---------|---------|--------|
| Proof Drop engine (`scout`) | Automate target research + artifact draft | search_web, sales ICP, claude_code, github |
| `gen_asset` tool | Text→image/3D for design pipeline | personal dept |
| discovery / studio / portal depts | Client-facing delivery | office.ts hierarchy |

Each must pass the **triple-filter:** real outcome + hiring gap + mostly reuse.

---

## Weekly cadence (10h/week)

| Day | Focus | Hours |
|-----|-------|-------|
| Mon | LinkedIn post + target list maintenance | 2h |
| Tue–Wed | Showcase build / Proof Drop craft | 4h |
| Thu | FounderOS maintenance (only if blocking delivery) | 1h |
| Fri | LinkedIn post + outreach / follow-ups | 2h |
| Sat | Optional: award submission, mood board research | 1h |

**Rule:** ~70% positioning/proof/distribution, ~30% build.

---

## Success criteria (30–45 days)

- 3 showcases live on proof.turicks.com
- ≥1 award submission
- LinkedIn cadence live (3–5/wk)
- 30-account niche target list complete

## Success criteria (60–90 days)

- 3–5 qualified conversations/month
- **1 client closed at ≥$8K**
