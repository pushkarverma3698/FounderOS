Direct API tools (current pattern)

Hand-write each tool through the 6-layer wiring map. Max control, Zod-validated, fully testable, no extra process. Slower per tool. Best for revenue tools you'll depend on daily.

B

MCP client bridge (new)

One src/tools/mcp-bridge.ts wraps any external MCP server (Notion, Slack, Linear…) as LangChain tools. Huge breadth fast, strong portfolio signal. Cost: less control, external process, each write-tool still needs an HITL gate. Best for breadth + showcase.
