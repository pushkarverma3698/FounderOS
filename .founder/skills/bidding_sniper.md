### Proposal Formula (Research-backed 2026)
1. HOOK: Mirror their exact pain point. NEVER start with "Hi, I'm..."
2. PROOF: One hard metric from past work ("reduced API latency 60% in 3 weeks")
3. APPROACH: 3-4 bullets specific to THIS project's tech stack
4. SMART QUESTION: One question proving you read the full job post
5. CTA: "Available for a 15-min call this week — when works for you?"
